# 准则与 Toeplitz 的绑定关系——cliff 的数学身份(仔细版)

这篇文档从头讲清楚一件事:**为什么 "Toeplitz 解" 只跟 full-frame 准则绑定,
跟 overlap-save 取帧、跟二阶统计(autoR/Gram)都不冲突**,以及 cliff 的精确
数学身份是什么。所有数字都来自可复跑的实验(见 §8)。

三个对象,一张表:

| 对象 | 是什么 | 与 overlap-save 冲突吗 |
|---|---|---|
| overlap-save 本身 | 取帧方式(滑窗 + 丢头留尾) | 中性,跟谁都不冲突 |
| autoR / Gram(跨分区二阶统计) | E[conj(X_p)·X_q] 的累积 | 不冲突——合法后继是 PFCG/fbtoe 里的每 bin Gram |
| Toeplitz 假设 + toeplitz(autoR)·w = rcross | 一种二阶更新规则 | 只与一个东西冲突:**[0;e] 准则** |

旧类(conjugate_toeplitz,已删除,git `2f23d9d` 可取回)恰恰是
" Toeplitz + autoR + overlap-save 取帧" 三者共存的——它吃的就是预 FFT 的
overlap-save 帧。所以"不能共存"的从来不是 overlap-save,而是
**Toeplitz ←→ full-frame 准则** 这一对。

---

## 1. 地基:两种卷积与 wrap

帧 `x_f = x[s : s+nfft]`(nfft=512,hop M=128,s = f·M)。用滤波器 w 预测帧内
位置 t 的回声,有两种读法:

- **线性模型**(真实世界):`ŷ_lin(t) = Σ_l w(l)·x(s+t−l)`。l > t 时读的是
  **帧开始之前的真实历史**。
- **循环模型**(FFT 一次乘法算的东西):`ŷ_circ(t) = Σ_l w(l)·x_f[(t−l) mod nfft]`。
  l > t 时下标绕回,**帧尾被当成帧前历史**读。

微例子:3 抽头 w,帧内位置 t=1——

```
线性:  ŷ(1) = w0·x(1) + w1·x(0) + w2·x(−1)      ← x(−1) = 帧前真实样本
循环:  ŷ(1) = w0·x[1] + w1·x[0] + w2·x[511]     ← 位置 −1 被读成帧的最后一个样本
```

循环模型相信"帧开始前的那一个样本 = 帧的最后一个样本"。这句话对真实信号
就是假的。两者之差叫 **wrap 项**:

```
wrap(t) = ŷ_circ(t) − ŷ_lin(t) = Σ_{l>t} w(l)·[ x_f((t−l) mod nfft) − x(s+t−l) ]
```

只对 t 小于滤波器支撑长度的**帧头**样本非零;只要路径支撑 ≤ nfft−M+1,
**帧尾 M 个样本上 wrap 恒等于零**。

## 2. 准则 = 给哪些样本打分

- **full-frame 准则**(旧类):给整帧 512 个残差打分,包括帧头。
  帧头正是循环模型说谎的地方,于是谎话进入了损失函数。
- **[0;e] / overlap-save 准则**(FD_NLMS、cgmdf、pfcg):只给最后 M=128 个
  样本(新进来的 hop)打分。§1 的恒等式保证在这些样本上循环 ≡ 线性,
  所以梯度是**精确的线性模型梯度**。

这就是 [0;e] cliff-free 的机制,一句话:**谎言只住在头部,[0;e] 不往那里看**。

## 3. full-frame 的 Hessian 为什么是循环矩阵(移位不变性)

J_ff(w) = Σ_f ‖C_f w − d_f‖²,C_f = x_f 的循环矩阵(第 t 行 = 第 t−1 行循环
右移一格)。循环矩阵对乘法与求和封闭:

- C_f^H·C_f 还是循环的;逐帧求和还是循环的 ⇒ **H_ff 严格循环**
  (实测结构误差 1.8e-16,§8)。循环 = 对角线为常数 = Toeplitz(在环上)。
- 被 512 点 DFT 对角化:每个频率 bin 一个标量。多分区(MDF)视角下,每个
  bin 内是 R×R 的分区 Gram,在宽平稳假设下对分区滞后 p−q Toeplitz
  (实测块内偏差 0.00%)。

几何说法:**打分全部样本 + 模型按循环移位生成 ⇒ 损失对循环移位不变 ⇒
移位不变的二次型 Hessian 必为循环矩阵**。注意这是逐帧成立的**代数事实,
不需要任何平稳性/随机性假设**——平稳性只在"跨帧累计的 autoR 仍保持
Toeplitz"那一层才需要。

所以 toeplitz(autoR)·w = rcross 确实是 full-frame 目标的法方程:
**在它自己的准则下,旧解没有任何数学错误**。问题在准则本身(下一节)。

## 4. cliff 的身份:伪解(三行推导)

把真实目标分解:`d_f = C_f·h + m_f`,其中 m_f = 线性真回声 − 循环模型输出
= wrap 项,**只在帧头非零**。full-frame 法方程:

```
(Σ C_f^H C_f)·w = Σ C_f^H d_f = (Σ C_f^H C_f)·h + Σ C_f^H m_f

⇒  w* = h + H_ff⁻¹·(Σ C_f^H m_f)
```

第二项就是伪解偏置:**确定性、系统性的,不随统计精度提高而消失**。
LS 面对的选择是:留在 h(帧头带着 wrap 残差),或者挪动 w 把 wrap 部分吸收
进滤波器。帧头有几百个被打分的纯虚构样本,天平必然倒向后者。w\* 就是
"如果世界真是循环的、什么 w 最优"的精确答案——**错误的地图上精确导航**。

数值(§8 演示,精确统计 + 精确求解):

| 数据 | w* 与真值距离 |
|---|---|
| 数据由循环模型生成(m ≡ 0) | −173 dB(任何时延,机器精度)|
| 数据是真实线性回声 | −8 ~ −13 dB(任何非平凡路径,含对齐时延)|

δ@0 也精确(−174 dB):滞后 0 的抽头永远不越界,wrap 不存在——这正是旧类
delay-0 探针能到 128 dB 的原因。

## 5. 换 [0;e] 之后,Hessian 怎么了

J_0e = Σ_f ‖G·C_f·w − G·d_f‖²,G = 尾部选择矩阵(只留最后 M 行)。

```
H_0e = Σ C_f^H·(G^H G)·C_f
```

G^H G 是 0/1 对角掩码,不是单位阵的倍数 ⇒ **H_0e 不再循环**。频域说法:
时域门控 = 频域卷积(掩码谱是缓衰减的 sinc 类核,把每个 bin 的误差泄漏给
邻居)——这就是 `docs/gate_dense_matrix.png` 里那个稠密矩阵的来历(对角
捷径丢 72% 的信息,稠密解 ≡ 门控 2.5e-16)。实测:跨 bin 耦合能量
**9.9%**(彩色激励)/ 0.4%(白噪声)。

所以 [0;e] 的真 Hessian:时间上不循环、频域上 bin 耦合——**连"每 bin 一个
矩阵"都不成立,更谈不上 Toeplitz**。我们试过的四种"保留二阶 + 换 [0;e]"
构造(Toeplitz、零头 Toeplitz、Hermitian 带状、精确上带)全部失败,失败的
正是这个绑定:它们全都假设了门控 Hessian 不具备的 per-bin 结构。

## 6. 旧机器 = 拿 full-frame 地图在 [0;e] 的地上走

把三层分开就清楚了:

- **overlap-save = 管道**:帧怎么进、怎么出。中性。
- **autoR = 测量仪**:量二阶统计。任何引擎里都合法。
- **Toeplitz 解 = 导航**:解 full-frame 法方程 = 问"full-frame 地图上哪最
  优"。地图换成 [0;e] 后导航作废——但它解出的地址本身没有错,只是那个
  地址在错误的地图上。

**PFCG 为什么无辜**:同一个 Gram 对象,用法不同。旧法把 Toeplitz 系统的
解**当作更新本身**(Gram 定义了目标 → 目标错则不动点错);PFCG 的梯度是
精确 [0;e] 梯度,Gram 只用来定步长/方向。不动点论证:更新
Δw = μ·M⁻¹·g(w),只要 M⁻¹ 有限,g(w)=0 ⇒ Δw=0 ⇒ **不动点集合与 M 无关**。
近似可以改变路径,永远不能改变终点。这就是 taxonomy 文档
(`autocorr_matrix_methods.md`)里 "form innocent, job decisive" 的准则层
版本:同样的矩阵,"定义目标" 与 "只定步长" 是两个工种。

## 7. 一般定律与三个实例

绑定关系的一般形式:**Toeplitz/循环结构 ⟺ 被打分准则(在其世界里的)
移位不变性**。"Toeplitz ←→ full-frame" 只是 overlap-save 家族里的特例。
三个实例把定律钉死:

1. **overlap-save + full-frame**:Hessian 严格循环(不变性成立),但被打分
   的世界(循环模型)与真实(线性)不符 ⇒ 不变的是错误地图 ⇒ 伪解/cliff。
2. **[0;e]**:世界对了,门控把移位不变性打碎(频域稠密)⇒ per-bin Toeplitz
   无从谈起(四种构造全灭)。
3. **纯 WOLA**(conjugate_full,已删除):世界对了、无时间 wrap(overlap
   是加性的),但**窗的渐变**把每 bin 的移位不变性打破 ⇒ 自己的 cliff,
   残余 ∝ (d mod hop)/hop,0.6–23 dB。

旁证(**Toeplitz 合法的地方**):WOLA 滤波器组家族(fbtoe)。分析滤波器组
用原型窗把频带真正隔开,每 bin 内统计近似移位不变 ⇒ per-bin Toeplitz 投影
无辜(0.4%),冻结 T 解 45.4 dB ≈ RLS 44.68 dB。滤波器组做了"频带隔离"
这件事,而裸 hop-DFT 分区基只在白/短相关激励下才等价地做到(见 §9)。

## 8. 不动点演示(`scratch_criterion_identity.py`)

纯固定点最小二乘:无自适应动力学、精确统计、512 抽头全自由度、彩色激励
(相关长度 ≈ 240 > hop)。`.venv/Scripts/python.exe scratch_criterion_identity.py`
(`--white` 切白噪声自检)。主表(彩色激励,NMSE 相对真路径,dB):

| 真实路径 h | [0;e] LS | FF·线性数据 | FF·圆模型数据 | per-bin Toeplitz·圆数据 |
|---|---|---|---|---|
| δ@0 | −165 | −174 | −174 | (见下) |
| 尾巴@0 (mod 0) | −163 | **−10** | −177 | +36(崩) |
| 尾巴@128 (对齐) | −159 | **−8.5** | −173 | +31(崩) |
| 尾巴@141 (mod 13) | −159 | **−8** | −173 | +22(崩) |

逐列读法:

1. **[0;e] LS**:该准则的不动点 = 真值,任何时延,机器精度。终点正确。
2. **FF·线性数据**:full-frame 不动点,真实数据。任何非平凡路径都有
   −8~−13 dB 的**确定性**偏置(含对齐);δ@0 例外(无 wrap)。错误终点,
   且被精确到达。
3. **FF·圆数据**:同一求解器、数据换成符合循环模型的。任何时延精确到
   −173 dB。**求解器无辜;错的是地图不是走路的人**——这就是"旧的逐 bin
   CG 解在它自己的准则下没有数学错误"的实证。
4. **per-bin 列**:对同一个系统按 per-bin(Toeplitz 或整块)求解。白噪声
   下也有 −23 dB 地板(Toeplitz 投影本身只损失 0.2 dB),彩色下直接崩。

结构测量:full-frame Hessian 循环误差 1.8e-16;块内 Toeplitz 偏差 0.00%;
跨 bin 能量:full-frame Hessian 0.3%(白)/ **13.5%**(彩色),
[0;e] Hessian 0.4%(白)/ 9.9%(彩色)。

## 9. 两个细化(演示给出的新信息)

**细化 1:per-bin 形式是第二层独立近似。** "toeplitz(autoR) 是 full-frame
的精确法方程"要补前提:块内 Toeplitz 精确(0.00%),但**"每 bin 一个矩阵"
这一步只在白/短相关激励下成立**——相关长度超过 hop 后,真 Hessian 在
hop-DFT 分区基下有 13.5% 跨 bin 能量,按 per-bin 解直接崩掉。所以旧机器
是**双层近似叠加**:(a) 准则层(full-frame 目标错);(b) 基底投影层(丢
跨 bin 耦合)。这也解释了 fbtoe/WOLA 家族为何 per-bin 合法:滤波器组把
频带真隔开了(0.4% 无辜),裸 hop-DFT 基对彩色激励做不到。

**细化 2:mod-M 尖锐形状在表示层,不在准则层。** 纯 full-frame 不动点的
偏置 ∝ 帧头重叠 ∝ 时延,**没有 mod-M 结构**(对齐 −8.5 vs sub-grid −8.1,
几乎一样)。旧类实测的尖锐定律(只有 delay mod M 重要;对齐 19–26 dB、
sub-grid 5.94)来自 per-bin/hop 网格机构与准则的交互(DATAFLOW §7)。
两层分工:**准则层给出"有偏伪解"这个身份,表示层给出 mod-M 这个形状**。

(边界说明:演示是准则层的理想化——精确统计、全时域自由度。旧类对齐
19–26 dB 比纯 FF 不动点还好,说明它的窗口化累积把不动点挪动过;演示证明
的是恒等式,不是复刻旧类的逐个数。)

## 10. 一句话

**overlap-save 是管道,autoR 是测量仪,toeplitz(autoR) 解是按 full-frame
地图走路——换 [0;e] 地图后导航作废,但管道和测量仪都还在用。** 当前
组合(overlap-save 取帧 + [0;e] 准则 + Gram 只定步长)就是每层各归其位
的形态。

## 11. 两个常见追问

**Q1:overlap-save / overlap-add 里,e 和 reference/mic 信号之间有漂移吗?**

准则层面**没有**——[0;e] 的恒等式本身就是对齐保证:e 残差化的正是本 hop 的
麦克风样本,回归子覆盖的恰好是预测这些样本所需的滞后。e 在帧内的尾部
位置不是"把 e 延迟了",而是频域对齐装置(rfft([0;e]) 在 nfft/hop 整数倍
bin 上 = e 的精确 hop-DFT,带已知相位)。看似"漂移"的三个无辜来源:

1. 块处理时延:拼接输出整体滞后于 mic(管道属性;WOLA 块引擎要丢弃前
   R−1 块,harness 适配器做时延补偿);
2. 测试数据自带的路径 bulk delay(x 与 d 天生错开,canonical 对差 800 样本);
3. 帧内位置簿记——e 只通过 FFT 消费,从不当作时间信号直接比对。

错位真正变成伤害的地方是准则拿错(亚 hop 时延 + full-frame 打分 = cliff):
那是打分几何错,不是 e 漂移。

**Q2:NLMS 用 e 更新 weight,为什么不能改用自相关矩阵更新?**

三层答案:

1. **NLMS 已经在用自相关矩阵**——对角分辨率。FD-NLMS 的每 bin 归一化
   P(k)=E|X(k)|² 就是 autoR 的对角线;NLMS 更新 = e 的精确 [0;e] 梯度 ×
   diag(autoR)⁻¹。问题从来不是"能不能用 autoR",是"用到什么分辨率、
   干什么活"。
2. **恒等式连接两条路**:每个被打分样本上 d = ŷ + e,于是
   `E[X*·d] = R·w + E[X*·e]`。误差法驱动 X*·e → 0;相关法解 R·w = E[X*·d]。
   理想统计 + R 为真 Hessian 时两者是同一个方程。相关法必须先**造一个
   Hessian 模型**才能解,而造得起的便宜模型(per-bin、Toeplitz、移位不变)
   在门控世界是错地图——三层损失叠加:准则层(full-frame 统计 → 伪解,
   §8 第 2 列就是相关法的落点)、表示层(per-bin 投影丢 13.5% 跨 bin 耦合)、
   轨迹层(累积 rcross 是非平稳世界的滞后模糊版,"解昨天的方程";fbtoe
   相关模式 9~26 dB vs RLS 44.68,δ/β 救不了;但平稳在网信号上深解是真的:
   d512@64s 38.08 > CG 36.91)。
3. **正确用法是冠军路线本身**:把 e 放进右边(autoR 只当曲率、不当目标),
   w += μ·T⁻¹·E[X*·e] = 正确目标上的 Newton 步——正是 fbtoe 的
   solver='rls'/gradient='error'(44.68)与 PFCG(26.31)。被禁止的只有一种
   用法:让 toeplitz(autoR)·w = E[X*·d] 把**目标**定义掉。

为什么 e 路线连 Hessian 都不用造?因为 [0;e] 恒等式让"本帧残差 × 回归子"
恰好是门控准则的精确瞬时梯度——真 Hessian 的作用结果免费出现在梯度里,
不需要显式组装那个稠密、bin 耦合的门控矩阵。相关法必须组装 Hessian 才
能解,而便宜的组装全是移位不变的——这就是绑定的根源。

## 12. 存在不是 full-frame 准则的 Toeplitz 方法吗?——存在,分三个等级

Toeplitz 的生存条件是"被打分世界的移位不变性"(§7),而不变性有三个来源,
对应三类方法:

| 等级 | 不变性来源 | 方法 | 实测 |
|---|---|---|---|
| 逐帧代数 | 循环移位封闭,每帧精确成立 | full-frame OLS 的 per-bin Toeplitz | Hessian 循环误差 1.8e-16;但打分世界假 ⇒ 目标偏 −8~−13 dB |
| **统计期望** | 平稳平均,N→∞ 收敛 | **时域 Wiener/Levinson Toeplitz,作用于 [0;e] 累积统计** | 投影残差 0.85%@300 帧 → 0.03%@3000;解 −40 → −63 dB,**无地板** |
| **按构造** | 滤波器组把准则本身搬进子带 | **fbtoe(冠军)**:WOLA 子带准则 + per-bin Toeplitz | bin 内投影 0.4% 无辜;冻结 T 解 45.4 ≈ RLS 44.68 |

关键对照(`--long` 实验,300 帧 vs 3000 帧):**时域 Toeplitz 残差
0.85% → 0.03%(统计近似,随数据愈合);per-bin 跨 bin 能量 9.9% → 10.8%
(确定性基失配,永不愈合)**。四次"per-bin 二阶当目标"构造失败的代数身份
就是后者。

fbtoe 合法的结构原因:WOLA 子带准则**本身**就是逐 bin 定义的
(Σ_k |子带误差(k)|²)——per-bin 不是对某个时域准则的近似,而是构造事实;
剩下的近似只有 bin 内 Toeplitz(0.4%,无辜)和子带/时域准则的等效性
(PR 设计保证)。对照:OLS/[0;e] 里 per-bin 是对时域准则的近似(跨 bin
~10%,确定性),这就是同一种"每 bin 一个矩阵"在 OLS 里死、在 WOLA 里
活的原因。(纯 WOLA 的窗会另开一个亚 hop cliff——§7 实例 3;fbtoe 的
几何处理了它。)

边界一句话:**死的不是 "Toeplitz × 某准则",而是 "裸 hop-DFT per-bin 基
× 时域准则(无论 full-frame 还是 [0;e])在彩色激励下"**。Toeplitz 本身
跟 full-frame 不绑定——它跟移位不变性绑定;full-frame 只是让不变性
"逐帧免费成立"的最方便但错误的方式,时域版用统计平均买,fbtoe 用滤波器组买。

## 13. 论文对照:freggradientconjugate.pdf(Lalos & Berberidis,EUSIPCO 2006)

**"定义目标"的判据**:迭代更新的停点方程里出现的是谁——更新式右端乘
conj(X) 的是**当前残差**(误差族,目标 = 你打分的准则)还是**累积的
x–d 统计**(统计族,目标 = 统计背后的模型)。CG 从不显式求逆矩阵,
但"求解 w"的迭代目的地**就是** R·w = b 的解——两句话不矛盾。

**论文属于统计族**(式 7/14:g = b − R·w,更新中无 e),但**不在禁区**:

- 式 (15)(16):X(k)、U(k) 都是 **[0; 块]** 零头补零谱;式 (17):V(k) 为
  带历史块的完整帧;式 (18)(19) 的乘积**尾部 M 点 = 精确线性相关,头部
  "× don't care" 丢弃**——即 [0;·] 纪律应用于统计计算。目标 = **线性模型
  的 Wiener 解**(期望无偏),与 [0;e] 不动点同地址。
- 单块结构(M 抽头、2M FFT):R 嵌入 2M 循环矩阵被 2M-DFT **精确对角化**,
  无多分区 per-bin 基那层近似。
- 落点 = §12 表第二行(统计期望级):无偏,代价是平稳性/累积滞后/条件数
  ——fbtoe 相关模式后验尸的"轨迹层"死因,非目标偏置。

**我们旧类(git 2f23d9d,legacy hop=None)恰好丢了论文的 don't-care 纪律**:
rcross ← conj(X_整帧)·Y_整帧(第 380 行:`Y_col = (E_zh if self.hop is not
None else Y)` 是两族分水岭),统计携带循环约定 → 不动点 = full-frame 循环
Wiener = 偏置伪解(代码注释自证:"scores the overlap-save head and has the
delay-mod-hop cliff");且多分区 per-bin 基叠加第二层近似。2026-09-24 的
hop 修复 = 把该行换成 E_zh,从误差侧重新引入零头纪律。

**互斥范围收窄**:与无偏互斥的是"**携带循环约定(整帧、不丢头)的统计**
定义目标",不是"统计定义目标"本身。统计干净(线性相关)时,相关法与
误差法的不动点同地址,差别只在轨迹层。仓库对照:

| 机器 | 右端乘 conj(X) 的 | 目标 | 结果 |
|---|---|---|---|
| 论文 FD-CG | b(线性相关累积,丢头) | 线性 Wiener | 期望无偏 |
| 旧类 legacy(hop=None) | Y(整帧谱,不丢头) | full-frame 循环 Wiener | cliff 5.94 |
| 旧类 [0;e] 模式 / 简化后类 | E_zh | [0;e] 最优 | 无偏 |
| pfcg(PAES 2006,另一篇) | e + Gram 定步长 | [0;e] 最优 | 26.31 |

(注意:pfcg 的来源是 PAES 2006 误差梯度论文,不是这篇;`results/
2026-10-01_class-simplify/conjugate_mdf.py` 快照是**简化后**版本——纯
[0;e] 误差族,无 Toeplitz/autoR,"CG"仅为命名血统;论文算法在仓库里的
实现在 git 2f23d9d 的 legacy 分支 = 后来独立成 conjugate_toeplitz.py 的那个,
已删。)

**与 PAES 2006(AES 6713,PBFDAF-CG)的关系:兄弟,不是父子。**
两篇同年发表(AES Paris 2006-05 vs EUSIPCO Florence 2006-09),互不引用
(时间上来不及),共享同一批祖先(Boray & Srinath 1992 自适应 CG =
PAES[5] = Lalos[7];Shynk 1992 频域自适应 = 两篇都引)。同一个 Wiener
目标(PAES 式 10 = Lalos 式 1),同一"每块一步 CG + 频域 overlap-save"
框架,但在关键处分叉:

| 维度 | Lalos(统计族) | PAES(误差族) |
|---|---|---|
| 梯度 | 法方程残差 g = b − Rw(R,b 递归累积) | 平均瞬时误差梯度(式 18),从不组装 R |
| 曲率 | 全 Toeplitz R + 精确线搜索(式 14) | 明确不用 Hessian、不用线搜索(引 Boray-Srinath 技巧) |
| 挡卷绕 | 统计侧:零头 X,U + don't-care(式 15–19) | 误差侧:E = F[0;e](式 6) |
| 结构 | 单块单通道均衡 | 多分区多通道 PBFDAF + 约束梯度投影 |

深层恒等式连接两族:**E[X\*e] = b − R·w**——PAES 的平均梯度(被估计量)
与 Lalos 的法方程残差(计算量)是同一个数学对象;期望意义下两族停点相同
(线性 Wiener)。仓库后代:PAES → pfcg(26.31);Lalos → 旧类 legacy 分支
(结构移植自其 Table 2,注释可证"paper Table 2: V^H D",但**丢了零头
don't-care 纪律**→ 整帧谱乘积 → 循环伪解 → cliff)。两族不互相支配:
平稳在网信号上统计族深解更强(fbtoe 相关模式 d512@64s 38.08 > 误差 CG
36.91),非平稳语音上误差族轨迹更优(44.68 vs 9–26)。

**w 更新视角(两篇的机械差异)**:外壳同为 w ← w + α·v、v⁺ = g⁺ + βv,
四个部件不同——(1) 梯度:Lalos g = b − Rw(统计模型残差,由式 14 递归
携带,精确簿记)vs PAES ∇ = 对过去 N 块用**当前 w 重滤波**取平均残差梯度
(式 18);两者数学上是同一个估计器(窗口平均 X*(d−ŷ(w)) ≡ b_win −
R_win·w),差别只在窗口形状(指数 λ vs N 块回放)与 R 是否物化;
(2) 步长:Lalos α = pᴴg′/pᴴRp(**精确线搜索,需要 R**——FD 里 R 以循环
嵌入特征值 D_R 递归维护,式 20)vs PAES 用相邻梯度差的割线估计(**无 R、
无线搜索**,Boray-Srinath 技巧);(3) 每块步数:Lalos 恰好 1 步/块 vs
PAES 至多 min(N,K) 步/块(每子步都要对 N 块重滤波,贵;我们移植实测
k_max>1 在语音上发散);(4) 结构:Lalos 单个 M 抽头滤波器 vs PAES 多分区
多通道 W 矩阵 + 每步约束梯度投影(式 9)。R 在 Lalos 里唯一的不可替代
用途是线搜索分母 pᴴRp——梯度本身和携带项 T(r_g)w 都可以靠"用当前 w
滤波"算出,不需要矩阵。仓库映射:pfcg = PAES 的 w 更新(gacc 换成增量
指数窗);旧类 = Lalos 骨架(统计 + T 加权步长)减共轭记忆、丢零头;
fbtoe-RLS = 两家杂交(误差族目标 + 逐 bin 全矩阵曲率)。

**谱系源头(Chang & Willson 2000,Table I = CG1)**:样本级 CG 解
R̂w = r̂——指数窗统计(其式 21–22)+ 残差递归(式 23)+ 精确线搜索 +
reset/PR-β,纯线性代数、不挑域,且其式 (17) 自注"适用于块处理"。**能**
实现在 overlap-save 上:Lalos 论文就是它的频域移植(其式 10–11 = CW 式
21–22 的块形式;式 14 = CW 式 23 的块形式;一步/块 = degenerated scheme
的块粒度版)。移植中唯一决定成败的细节仍是统计的零头/don't-care 纪律
(干净 → 期望无偏;整帧循环乘积 → 伪解 cliff)。多分区 per-bin 化时再叠
第二层近似(彩色激励 9.9–13.5% 跨 bin)。

**Q3:Chang-Willson Table I 能不能实现成 overlap-save + 多分区?**
分两半答。**单块:能,且零近似**——M 抽头 R̂ 嵌入 2M 循环矩阵被 DFT
精确对角化,Table I 的每个部件(TToeplitz 统计、精确线搜索、共轭记忆、
残差递归)原样保留(= Lalos)。**多分区 per-bin:机制上能(= 旧类),
但 bin 解耦从构造事实降级为近似**——白噪声下是纯统计涨落(跨 bin 能量
0.302%@300 → 0.031%@3000 帧,会愈合;per-bin 解 −22.5 → −32 dB);彩色
激励下含确定性分量(9.9% → 10.8%,永不愈合;per-bin 解直接崩)。机制:
per-bin 期望 Gram E[X\*(k,p)X(k',p')] 仅白噪声下严格解耦(δ 相关),彩色
的部分窗求和产生 Dirichlet 型泄漏,相关长度 ≳ hop 后到 ~10%;而同一算子
在时域全长仍是那个 L×L Toeplitz——**多分区 per-bin 只是选了一个不对角化
它的基底;分区不是罪,裸 hop-DFT 基底 + 彩色激励才是**。要让 Table I 在
多分区 + 彩色下完整复活,基底必须换成滤波器组(= fbtoe:0.4% 无辜投影,
冻结 T 解 45.4)。多分区本身的意义是时延:单块 L 抽头需 2L 帧,分区降到
~M——工程选择从来不是"要不要分区",而是"分区用什么基底"。
